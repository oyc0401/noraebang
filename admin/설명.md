2026-06-22 현재 파이프라인 설명

1. TJ곡 신곡을 얻어온다.
최신곡 api: TJ곡 최신곡 api를 통해서 신곡이 발견되면, TJSong에 넣고 신곡큐에 넣는다.
가수 전체 검색: 최신곡 api에 안뜨는 곡을 검색하기 위해서 아티스트 검색을 통해서 신곡을 얻어온다.

2. 신곡큐 넣기
신곡큐에 들어갈 때는 곡의 카탈로그를 추론해서 더한다.

3. 곡-가수 큐에 넣기
신곡큐에 있는 jpop들은 관리자가 곡가수큐로 이동시킨다.
해당 큐에 들어가기 전에 모든 곡의 tjArtist, 아티스트이름과 비교해서 기존아티스트가 있는지 확인한다.
없으면 아티스트 없음으로 큐에 들어간다.

4. 아티스트 생성 큐에 넣기
관리자가 곡-가수 큐에있는 아티스트 없는 곡을 아티스트 생성큐에 넣을 수 있다.
아티스트 생성큐 진입점에선 다음과 같은 일이 일어난다.
유튜브, 스포티파이: 해당곡의 아티스트를 검색해서 메인, 토픽, 스포티파이 채널을 얻는다. 여기서 썸네일도 얻는다.
nameKo: 유튜브의 이름을 구글에 검색해, ai에게 전달해 한국어 이름을 얻는다.
nameJa,Latin: 해당 이름이 일본어인지 영어인지 판단해서 넣는다.
발음: kanabarum, konglish를 사용해서 발음을 얻는다.

아티스트 생성큐에있는 정보를 보고 아티스트를 생성하면 곡-가수큐에 해당 곡이 있다면 해당 곡을 큐에 다시 넣음으로 인해서 정보를 업데이트한다.
만약에 해당곡이 곡-가수큐에 없다면 곡-가수큐에 넣지 않는다.
