# 데이터 정제 핵심 스크립트

## 블로그에서 jpop 아티스트, 곡을 크롤링해서 저장한다
이유: jpop가수, jpop곡의 한국이름을 알기 위해서! (ky, joysound도)
Artist테이블, Song테이블에 저장한다.

## Atrist의 Slug를 수동 생성한다.

## tj곡을 테이블에 저장한다.

## tj곡을 아티스트배열로 전처리한다. (정규화)

## tj곡에 해당되는 아티스트를 생성한다.

## tj곡들을 Song에 등록시킨다.

## tj곡으로 썸네일을 생성한다.

## 중복되는 가수를 병합시킨다. (수기)

## Artist의 유튜브 주소를 획득한다.

## Artist의 유튜브 주소를 수정한다. (수기)

## 유튜브채널로 아티스트 썸네일을 생성한다.

## 가수의 곡의 분포를 통해서 카탈로그를 생성한다. (K-POP)

## 가수의 스포티파이 ID를 획득한다.

## 가수의 스포티파이 ID를 수정한다. (수기)

## 가수의 스포티파이 ID를 통해서 스포티파이 트랙을 획득한다.

## MusicBrainz를 통해서 곡의 원본이름을 가져온다.

## 가수, 곡의 다국어 이름을 등록한다.

## 스포티파이의 같은 트랙끼리 그룹을 만든다. (정규화)

## 스포티파이의 그룹을 병합한다. (수기) 

## 스포티파이트랙과 Song을 매핑시킨다. (수기)
