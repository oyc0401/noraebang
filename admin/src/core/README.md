# 데이터 정제 핵심 스크립트

## 블로그에서 jpop 아티스트, 곡을 크롤링해서 저장한다
이유: jpop가수, jpop곡의 한국이름을 알기 위해서! (ky, joysound도)
Artist테이블, Song테이블에 저장한다.

## Atrist의 Slug를 수동 생성한다.

## tj곡을 테이블에 저장한다.

## tj곡을 아티스트배열로 전처리한다. (정규화)

## tj곡에 해당되는 아티스트를 생성한다.

## tj곡들을 Song에 등록시킨다.

## tj곡으로 썸네일을 생성한다.

## 중복되는 가수를 병합시킨다. (수기)

## Artist의 유튜브 주소를 획득한다. (일일 퀘스트)
유튜브 api 키 여러개로 매일매일 획득해야함.

## Artist의 유튜브 주소를 수정한다. (수기)

Artist의 중복된 유튜브 주소 찾기

어드민 페이지로 직접 검토, 수정

## 유튜브채널로 아티스트 썸네일을 생성한다.

## 가수의 곡의 분포를 통해서 카탈로그를 생성한다. (K-POP)

## 가수의 스포티파이 ID를 획득한다.

## 가수의 스포티파이 ID를 수정한다. (수기)

## 가수의 스포티파이 ID를 통해서 스포티파이 트랙을 획득한다.

## MusicBrainz를 통해서 곡의 원본이름을 가져온다. (장기 작업)
1초에 1개씩 얻을 수 있는데 곡의 개수가 너무 많아요

## 가수, 곡의 다국어 이름을 등록한다.
한국어/일본어 분리

## 스포티파이의 같은 트랙끼리 그룹을 만든다. (정규화)

## 스포티파이의 그룹을 병합한다. (수기) 

## 스포티파이트랙과 Song을 매핑시킨다. 

## Song이랑 스포티파이가 잘 매핑되었는지 확인한다 (수기)

## Song에 들어있지 않은 스포티파이 트랙을 Song에 추가한다.

## 곡의 한국어 이름을 유튜브 api로 얻는다. (수기)
