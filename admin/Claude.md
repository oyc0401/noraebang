# 어드민 사이트 규칙

폴더 안에는 page.tsx, action.ts가 존재한다.

### /app에서는 다른 폴더를 의존하지 않는다.

어드민 페이지는 금방 생기고 금방 사라지고 요구사항이 무궁무진하게 생기기때문에 다른 코드를 의존하지 않게 함으로써 변경이 쉽게 한다.

/lib, /service 폴더는 의존 가능하고 깔끔하게 관리하자. 재사용율 100%임.

/script 안에서는 폴더별로 외부 의존하지 않도록 한다.

아무튼 알잘딱으로 너무 추상화 하지 마세요!!!


### 타입 제한 풀림
any 많이 써도 됩니다. 돌아가기만 한다면요.

### 서버액션 사용
action.ts에서는 prisma를 사용하는 서버액션 함수들이다.

화면은 컴포넌트 분리를 하지 않아도 된다.

다른 폴더를 의존하지 않으므로 하나의 파일의 줄수가 2000이 넘어가도 된다.

되도록 파일분리를 하지 않는다.

## 디자인 규칙
버튼 같은건 cursor:pointer로 해주세요!

해당 화면은 관리자페이지 이므로 디자인은 UI에는 크게 신경을 안써도 UX는 좋도록 해주세요.
버튼 덕지덕지 넣을거라 확장성 좋도록!
로딩상태 구현 안해도 돼요! 오류메시지는 보여주면 좋고요
